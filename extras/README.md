# extras

Kept for reference, not part of the installed set.

- **`driftwm-wormholed`** — from the earlier "regions and gates" layout: park the
  camera inside a gate at (±4800, 0) for about a second and it throws you to the
  far side of the canvas. It still runs, but the solar system draws no gates, so
  the teleport zones would be invisible. Left here rather than deleted in case
  you want to build a gate layer of your own.

The two supported opt-in extras live in `bin/` and are documented in the main
README: `sol-planetarium` (idle orbit) and `sol-spin` (circle gesture).
